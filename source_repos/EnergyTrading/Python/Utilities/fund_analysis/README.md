# Fund Analysis Project 
This project is created for processing, analysing, modeling and forecasting energy prices from fundamental data

## Features
- Load data from multiple sources
- Process and connect data to structures used for analysis/modeling
- Analyse and model created data structures
- Work with obtained data structures
- Output various forms of forecast raw data

## Instalation

git clone https://github.com/yourusername/fund_analysis.git

cd fund_analysis

python -m venv venv
source venv/bin/activate  # On macOS/Linux
venv\Scripts\activate     # On Windows

pip install -r requirements.txt
