# Project Structure Guide

## Main Directories
- **src/**: Production code and core business logic
- **tests/**: Unit tests (write tests first - TDD)
- **uat/**: User acceptance testing and validation
- **config/**: Configuration files and settings
- **logs/**: Application logs and runtime output
- **backup/**: Obsolete files (never delete anything)
- **sandbox/**: Development workspace and experimentation
- **docs/**: Documentation and design notes
